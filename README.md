# BookADI: Santa Biblia Libre para el mundo

Edición interactiva para Windows que organiza la Santa Biblia Libre para el
Mundo como un atlas de lectura y estudio. Incluye navegación por capítulos y
versículos, búsqueda, rutas temáticas, glosario, anotaciones, progreso y grafos
2D y 3D.

## Instalación

1. Descarga `BookADI.Biblia.Setup.1.1.0.exe` desde la sección Releases.
2. Ejecuta el instalador y elige la carpeta de destino.
3. Abre **BookADI Biblia** desde el acceso directo del escritorio o el menú
   Inicio.

El instalador incluye el lector y sus dependencias. No requiere ADI Platform,
Node.js ni conexión a Internet para leer el contenido.

## Compatibilidad

- Windows 10 u 11 de 64 bits.
- Pantalla con resolución mínima recomendada de 1280 x 720.
- Aproximadamente 300 MB libres durante la instalación.

## Integridad

Cada versión publicada incluye `SHA256SUMS.txt`. En PowerShell puedes verificar
el instalador con:

```powershell
Get-FileHash -Algorithm SHA256 ".\BookADI.Biblia.Setup.1.1.0.exe"
```
